# Материалы курса — Нурыева Лилия Хатмулловна

Опубликованный сайт: <https://bat801.github.io/lilium/>

Статический сайт-архив учебных материалов курса «Достижение личностных, метапредметных и предметных результатов на уроках иностранного языка». Сделан на чистом HTML5, CSS и минимальном JavaScript: без фреймворков, сборщиков, npm и внешних шрифтов.

## Структура проекта

```
index.html                  главная: о преподавателе, о курсе, оглавление
listening.html              аудирование
reading.html                чтение
grammar-vocabulary.html     грамматика и лексика
speaking.html               говорение
writing.html                письмо
project-role.html           Модуль 6: роль проектной деятельности
project-organization.html   Модуль 6: организация проектной деятельности
404.html                    страница «не найдено» для GitHub Pages
style.css                   все стили
script.js                   подсветка активного пункта меню
materials_from_course.txt   исходные материалы (не изменять)
.gitignore                  служебный файл Git
.nojekyll                   отключает обработку Jekyll на GitHub Pages
README.md                   эта инструкция
```

Все HTML-файлы лежат в корне, пути относительные — сайт можно открывать локально и размещать в подпапке на GitHub Pages.

## Как открыть локально

Самый простой способ — открыть `index.html` двойным щелчком в браузере.

Если нужен локальный сервер (например, для проверки на телефоне в той же сети):

```
python -m http.server 8000
```

Затем открыть `http://localhost:8000/`.

## Публикация на GitHub Pages

Сайт опубликован: <https://bat801.github.io/lilium/> (репозиторий: <https://github.com/bat801/lilium>).

Настройки публикации: **Settings → Pages → Source: Deploy from a branch → ветка main → папка / (root)**. Файл `.nojekyll` в корне отключает обработку Jekyll, чтобы все файлы отдавались как есть.

Если понадобится развернуть сайт в новом репозитории: загрузите все файлы из этой папки в корень репозитория, включите Pages по инструкции выше — через 1–2 минуты сайт будет доступен по адресу `https://имя-пользователя.github.io/имя-репозитория/`.

## Как обновить сайт

После правки файлов отправьте изменения в репозиторий:

```
git add -A
git commit -m "Обновление материалов"
git push
```

Через 1–2 минуты изменения появятся на опубликованном сайте.

## Как править тексты

Тексты находятся прямо в HTML-файлах, внутри обычных тегов:

- `index.html` — блоки «О преподавателе», «О курсе» и оглавление «Материалы курса»;
- `listening.html` — видео и советы по аудированию;
- `reading.html` — задания по чтению и советы;
- `grammar-vocabulary.html` — задания «Vacation plans», «Frightening News» и этапы обучения лексике;
- `speaking.html` — видео, задание-интервью и советы;
- `writing.html` — письменная работа и письмо Ronny;
- `project-role.html` — лекция о роли проектной деятельности и видеолекция;
- `project-organization.html` — лекция об организации, темы проектов и дорожная карта.

Что важно знать при правке:

- **Ответы** скрыты в `<details class="answer">`; строка `<summary>` — это кнопка «Показать ответ».
- **Тексты и варианты** скрыты в `<details class="spoiler">`.
- **Метка «Материал пройден»** — это `<span class="badge">Материал пройден</span>` в шапке задания. Чтобы убрать метку, удалите этот элемент.
- **Пропуски** в текстах оформлены как `<span class="gap">_______</span>`.
- **Видео** — это `<iframe>` внутри `<div class="video">`; под ним в `<p class="video-caption">` находится резервная ссылка на Rutube или VK. При замене видео обновите и `src` у iframe, и ссылку в подписи. Автозапуск отключён: воспроизведение начинается только по кнопке play (у Rutube параметр `autoplay=false`, у VK `autoplay=0`) — не добавляйте параметры автозапуска.
- **Стили** меняются в `style.css`, логика меню — в `script.js`. Классы и структуру лучше не переименовывать.
- Файлы должны сохраняться в кодировке **UTF-8**.
- Исходный файл `materials_from_course.txt` — архивный источник, его не нужно редактировать для изменений на сайте.

2. `[УТОЧНИТЬ УСЛОВИЕ ЗАДАНИЯ]` — на странице `writing.html`, в задании «Письменная работа по теме "Письменная речь"».
